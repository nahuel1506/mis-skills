# Cómo conservar el contexto entre pasos

Consultá esta guía si cambia la persona, la sesión, el entorno o la cantidad de contexto que conviene llevar al siguiente paso. Decidí según qué necesita conservar ese trabajo y qué herramientas están disponibles.

| Situación | Opción |
| --- | --- |
| El siguiente paso depende de matices, números o excepciones que solo están en esta conversación | Continuá en la misma sesión mientras resulte manejable. |
| Otra persona, sesión o agente va a retomar el trabajo | Compartí un `transferir-contexto` o el artefacto acordado, con referencias a las fuentes necesarias. |
| El contexto acumulado dificulta continuar, y los acuerdos todavía importan | Resumí o compactá preservando decisiones, restricciones y preguntas abiertas. |
| El siguiente trabajo es independiente y la sesión anterior no aporta | Empezá con un contexto nuevo. |
| Hay una investigación o revisión acotada que gana con una lectura independiente | Delegala si el entorno lo permite. Pasá el alcance y las fuentes concretas. |

Conservá en la transición el objetivo, las decisiones con sus motivos, las condiciones exactas, los límites de prueba y las dudas abiertas que el siguiente paso necesite para cumplir lo acordado. Enlazá el glosario, el ADR, la spec, el ticket o el prototipo si ya existen.

Por ejemplo, de entrevista a spec puede convenir continuar en el mismo chat para mantener los matices. De prototipo a implementación suele alcanzar con la pregunta, los escenarios que se probaron, el resultado y una referencia al experimento. El tamaño de contexto de un modelo no determina por sí solo cuál de estas opciones conviene.
